El sistema está estructurado bajo una arquitectura de **Monolito Modular**, comenzando por el **Módulo N° 1: ATS / Contratación Masiva** y preparado para incorporar progresivamente otros módulos (Nómina, Inventarios, Finanzas, etc.).

- **Frontend:** Angular (Web Application Responsive / PWA).
    
- **Backend:** FastAPI (Python).
    
- **Base de Datos:** PostgreSQL (Local en desarrollo, Cloud SQL GCP en producción).
    
- **Orquestación IA:** LangGraph.
    
- **Modelos de IA:** Geminy, Chatgpt.
